# 🖼️ Image Gallery

A modern and responsive image gallery website built with React. This project was developed as part of my frontend development internship task, focusing on responsive design, smooth interactions, and a clean user experience.

## 🚀 Live Demo

🔗 **Live Website:** [ https://image-gallery-delta-lilac.vercel.app/ ]

## 📸 Preview

The website is fully responsive and designed to work smoothly across:

- 💻 Desktop / Laptop
- 📱 Mobile devices
- 📟 Tablet devices

## ✨ Features

- 📷 Responsive image gallery
- 🔍 Image preview / lightbox
- ⏭️ Next and previous image navigation
- 🗂️ Category-based image filtering
- 📱 Mobile-friendly responsive layout
- 🎨 Modern and clean UI
- ✨ Smooth hover effects and animations
- ⚡ Fast image rendering
- 🖥️ Optimized for different screen sizes

## 🛠️ Technologies Used

- **React.js**
- **JavaScript (ES6+)**
- **Tailwind CSS**
- **React Icons**
- **Framer Motion**
- **Vite**
